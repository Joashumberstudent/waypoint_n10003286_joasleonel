# Waypoint

Waypoint is a Django web application for discovering and managing hiking trails.

The project combines a Python domain engine with a Django web application,
database models, relationships, templates and an administration interface.

## Features

- Trail catalog
- Trail details
- Trail reporting form
- Trail search
- Park management
- Trail/Park relationship
- Django administration
- Open-trail filtering
- Distance value object
- Automated tests

## Requirements

- Python 3.11+
- Django 4.2
- Git
